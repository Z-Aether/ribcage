Welcome to {{ marathon_name }}

{{ marathon_name }} is where the group plans and runs one film marathon: suggest films, vote on them, and follow the evening.

  1. Suggest{% if now == 'suggest' %} now{% endif %}

    Put forward the films you want to watch, each with a line on why, and read what everyone else has suggested. Click a film to open it: read every note in full, write your own, see its trigger warnings and correct its runtime. A click outside it, Escape or Save closes it again, and you can withdraw your own suggestion while nothing holds it.

    Then suggestions close while the admin chooses which films go to the vote, and notes stay writable.

    2. {% if now == 'suggest' %}{% include "phase/how_it_works_button.html" %}{% endif %}

  2. Vote{% if now == 'vote' %} now{% endif %}

    Drag each film into a band, from +3 down to −1; a film left in Unsorted counts as don't mind. The Veto band is I won't be in the room, and your note on the film is your veto's reason. Mark the films you've seen with 👁. A tile opens as its card on a click, where you can still write your note. A tile's frame shows:

    {% include "components/ballot_legend.html" with marks_only=True %}

    Press I'm done when you've finished. Scores stay hidden until VOTE closes, then everyone's are shown by name.

    3. {% if now == 'vote' %}{% include "phase/how_it_works_button.html" %}{% endif %}

  3. The evening{% if now == 'evening' %} now{% endif %}

    Voting closes and everyone's scores open, by name, while the admin builds the evening. Then comes the night itself, with what's on now and what's next.

    4. {% if now == 'evening' %}{% include "phase/how_it_works_button.html" %}{% endif %}

Content warnings

You can name topics you want to be warned about, and films that carry them are marked for you alone. That list is private to you in the app.

The admin and the host of the server can technically read it, as they can read everything stored here. It is deleted when the marathon is torn down.
